🔧 Utility Skills — Ferramentas simples e diretas

Uma utility skill é uma ferramenta especializada de propósito único. Ela resolve um problema específico e bem definido, com entrada previsível e saída consistente. Pense nelas como funções de utilidade: encurtam URLs, formatam texto, convertem dados, calculam métricas.

.claude/commands/bitly-utm.md Utility Skill 
# URL Shortener + UTM Tagger

## Tarefa
Encurtar uma URL longa e adicionar parâmetros UTM
para rastreamento de analytics.

## Input esperado
O usuário fornece:
1. URL original (longa)
2. Campanha: nome da campanha (ex: "lancamento-curso")
3. Fonte: de onde vem o tráfego (ex: "instagram", "email")
4. Tipo de mídia: "social", "email", "paid", "organic"

## Processo
1. Monte a URL com parâmetros UTM no formato:
   {url}?utm_source={fonte}&utm_medium={tipo}&utm_campaign={campanha}

2. Use WebFetch para encurtar via Bitly API:
   POST https://api-ssl.bitly.com/v4/shorten
   Header: Authorization: Bearer {BITLY_TOKEN}
   Body: {"long_url": "{url_com_utm}"}

3. Se a API Bitly não estiver disponível, retorne
   a URL com UTM sem encurtar + aviso.

## Output
- URL curta: bit.ly/xxxxx
- URL completa com UTM (para verificação)
- Preview: como ficará no analytics

## Casos de uso ideais
- Links para bio do Instagram
- Links em emails de campanha
- Links em posts de redes sociais

Fluxo de uma Utility Skill — Simples e Previsível

Input
URL + parâmetros UTM
→
Processamento
Monta URL → chama Bitly
→
Output
bit.ly/xxxxx rastreável

Utility skills têm fluxo linear e determinístico. Dado o mesmo input, sempre produzem o mesmo tipo de output. Não precisam "pensar" — só executar.

🎯 Quando Utility Skills São a Resposta Certa

✓
Formato fixo e determinístico

O output ideal é sempre o mesmo independente de quem usa. Ex: calcular RPM, converter JSON para CSV.

✓
Tarefa técnica mecânica

Conversão de formatos, cálculos, formatação padronizada — não requer análise criativa.

✓
Volume alto, pouco contexto

Precisa executar 20x por semana, mas a tarefa não muda com quem você é ou o que você faz.

✓
Resultado verificável objetivamente

Qualquer pessoa consegue verificar se a saída está correta sem entender o contexto de negócio.

🧠 Super Skills — Sistemas estratégicos vivos

Uma super skill é um sistema que cresce em valor com o uso. Ela conhece o negócio em profundidade, acessa dados externos em tempo real, aprende com interações anteriores e melhora continuamente. Não é uma ferramenta — é um ativo digital estratégico.

Arquitetura: Utility Skill
1 arquivo .md simples
↓
instrução direta (10-20 linhas)
↓
output padronizado
Independente do tempo de uso
Arquitetura: Super Skill
skill principal .md (contexto + lógica)
↓ conecta a
memory.md
contexto persistente
WebSearch
dados em tempo real
performance.md
histórico do negócio
WebFetch
APIs externas
↓
output estratégico + aprendizado
Valor cresce a cada uso
.claude/commands/signal-dashboard.md Super Skill — INEMA 
# Signal Dashboard — Inteligência de Conteúdo

## Identidade
Você é o analista de inteligência de conteúdo do INEMA.
Seu trabalho é separar sinal de ruído e identificar
oportunidades de conteúdo com alta probabilidade de sucesso.

## Contexto do negócio (leia antes de executar)
- Canal: INEMA.CLUB — educação sobre IA e automação
- Audiência: profissionais 28-45 anos, renda média-alta
- Tom: analítico, baseado em dados, sem hype
- CTR médio alvo: >5% no YouTube, >3% no Instagram
- Publicação: 2x/semana YouTube, 5x/semana IG

## Processo de coleta de sinais (execute nesta ordem)

### Fase 1 — Tendências macro (use WebSearch)
Buscar nas últimas 72h:
- "AI tools announcement site:techcrunch.com OR producthunt.com"
- "automação inteligência artificial site:reddit.com/r/brasil"
- "claude anthropic OR openai announcement"

### Fase 2 — Benchmarks do nicho (use WebFetch)
Verificar últimos 7 dias em canais concorrentes:
- Extrair títulos com >100k views (nicho PT-BR)
- Identificar formato: tutorial, opinião, análise, review

### Fase 3 — Cruzamento com histórico
Comparar com .claude/memory/channel-performance.md:
- Quais formatos performaram acima da média?
- Há sobreposição com tópicos já publicados?

## Output esperado
### Dashboard de Sinais (formato padronizado)
**🔴 URGENTE (janela < 48h):** [lista ou "nenhum"]
**🟡 QUENTE (próximos 7 dias):** [lista]
**🟢 PIPELINE (próximos 30 dias):** [lista]

Para cada sinal:
- Oportunidade: [descrição em 1 linha]
- Evidência: [dado específico que justifica]
- Ângulo único: [como diferenciar dos concorrentes]
- Formato recomendado: [tutorial/análise/review/etc]
- Estimativa de CTR: [baseado em similares históricos]

🧠 Os 5 Pilares de uma Super Skill

P1
Contexto estratégico profundo: conhecimento do negócio, audiência e objetivos embutido no arquivo — não precisa ser repassado a cada uso
P2
Dados externos em tempo real: acesso a WebSearch, WebFetch, APIs — informação atual, não fotografia do passado
P3
Memória persistente: lê arquivos .md de memória com decisões, aprendizados e contexto de sessões anteriores
P4
Ciclo de melhoria: mecanismo para atualizar memória e refinar comportamento com base em feedback e resultados
P5
Capacidade de julgamento: analisa, prioriza e recomenda baseada em múltiplos fatores — não apenas executa mecanicamente

📊 Quando usar cada tipo

A decisão entre utility skill e super skill não é sobre complexidade técnica — é sobre valor estratégico e necessidade de contexto. Usar o tipo errado para o problema certo é desperdiçar energia na direção oposta do que você precisa.

Tabela Comparativa — Critérios de Decisão

Critério 🔧 Utility Skill 🧠 Super Skill
Frequência de uso Alta (diário/mecânico) Estratégica (semanal/decisório)
Contexto necessário Baixo/Nenhum Alto/Específico do negócio
Dados externos Raramente Essencial
Evolução com tempo Não precisa Cresce em valor
Output esperado Sempre igual/padronizado Contextualizado, adaptado
Tempo de construção 15-30 minutos 2-8 horas + refinamento
ROI crescente? Fixo desde o dia 1 Composto com o uso

Fluxograma de Decisão — Utility ou Super Skill?

Você tem um processo repetitivo para automatizar
↓
Um freelancer que nunca te viu poderia usar essa skill com os mesmos resultados?
SIM ↓
🔧 Utility Skill

Resultado independe de quem você é ou o que você faz

NÃO ↓
Ele precisaria de briefing sobre seu negócio?
🧠 Super Skill

💡 A Regra de Ouro

Se um freelancer que nunca te viu poderia usar a skill com os mesmos resultados que você, é utility skill. Se ele precisaria de um briefing de 2 horas sobre seu negócio, sua audiência, seu histórico e seus objetivos antes de usar — é super skill. A profundidade do contexto necessário é o divisor definitivo.

🛠️ Exemplos de Utility Skills

Utility skills têm um lugar importante no arsenal de qualquer criador digital. Elas automatizam o trabalho mecânico, liberando energia cognitiva para o trabalho estratégico que só você pode fazer.

.claude/commands/format-markdown.md Utility — Formatação 
# Markdown Formatter

## Tarefa
Converter texto bruto (sem formatação) em Markdown
bem estruturado, com hierarquia lógica e consistente.

## Regras de formatação
- Título principal: H1 (uma única linha, no topo)
- Subtítulos: H2 para seções, H3 para subseções
- Listas: bullet points para itens sem ordem, numeração para passos
- Código: sempre entre backticks (inline ou bloco)
- Links: [texto descritivo](url) — nunca URLs nuas
- Negrito: apenas para termos-chave ou avisos críticos
- Itálico: apenas para ênfase leve ou termos técnicos

## O que NÃO fazer
- Não adicionar conteúdo novo além do que foi fornecido
- Não remover conteúdo original
- Não reordenar seções (apenas formatar o que existe)

## Output
O texto formatado em Markdown, pronto para uso.
Sem comentários ou explicações adicionais.
Quando usar: converter transcrições de reuniões, emails brutos, notas soltas para documentos legíveis.
.claude/commands/metrics-calculator.md Utility — Cálculo 
# Metrics Calculator — Criadores de Conteúdo

## Tarefa
Calcular métricas de performance a partir de dados brutos
fornecidos pelo usuário.

## Métricas disponíveis

### YouTube
- RPM = (receita / views) × 1000
- CTR = (cliques / impressões) × 100
- Taxa de retenção média = (minutos assistidos / (views × duração)) × 100
- Crescimento = ((seguidores_atual - seguidores_antes) / seguidores_antes) × 100

### Instagram
- Taxa de engajamento = ((likes + comentários + salvamentos) / alcance) × 100
- Taxa de salvamento = (salvamentos / alcance) × 100
- Alcance orgânico = (alcance_orgânico / seguidores) × 100

### Email
- Taxa de abertura = (aberturas únicas / enviados) × 100
- CTR email = (cliques / aberturas) × 100
- ROI campanha = ((receita - custo) / custo) × 100

## Output
Para cada métrica calculada:
- Valor calculado (com 2 casas decimais)
- Benchmark do setor (quando disponível)
- Avaliação: 🔴 Abaixo / 🟡 Na média / 🟢 Acima
Quando usar: análise semanal de métricas, relatórios para sponsors, comparações de performance entre períodos.
.claude/commands/thread-converter.md Utility — Conversão de Formato 
# Thread Converter — Blog Post para Twitter/X

## Tarefa
Converter um artigo de blog ou texto longo em
uma thread para Twitter/X otimizada.

## Regras de conversão
- Tweet 1: gancho (o ponto mais impactante do artigo)
- Tweet 2: contexto (por que isso importa)
- Tweets 3-8: os pontos principais (1 por tweet)
- Tweet final: CTA + link para o artigo original

## Formato de cada tweet
- Máximo 280 caracteres
- Sem abreviações (escreva completo)
- Números específicos > afirmações vagas
- Cada tweet deve funcionar sozinho (fora da thread)

## Numeração
Adicione "1/" no primeiro tweet para indicar thread.
Não adicione número nos demais (o Twitter faz automaticamente).

## O que preservar
- Dados e citações do original (verbatim)
- Exemplos específicos mencionados
- Tom e voz originais do autor

## Output
A thread completa, tweet por tweet, numerados
claramente para facilitar copiar e colar.
Quando usar: republicar conteúdo de blog no Twitter/X sem reescrever do zero. Alta frequência, zero julgamento necessário.

🚀 Exemplos de Super Skills

Super skills são onde o verdadeiro valor estratégico é criado. Cada uma representa contexto acumulado, decisões registradas e aprendizado que não pode ser replicado rapidamente por ninguém que comece do zero.

.claude/commands/content-strategy.md Super Skill — Estratégia 
# Content Strategy — Planejamento de Conteúdo Mensal

## Identidade desta skill
Você é o estrategista de conteúdo sênior do canal.
Seu trabalho é analisar o contexto completo e propor
um calendário de conteúdo otimizado para o próximo mês.

## Contexto estratégico permanente
Leia ANTES de propor qualquer conteúdo:
- .claude/memory/channel-profile.md (quem somos)
- .claude/memory/audience-data.md (quem é nossa audiência)
- .claude/memory/performance-history.md (o que funcionou)
- .claude/memory/content-calendar.md (o que já foi publicado)

## Análise de mercado (execute toda vez)

### Coleta de dados externos (use WebSearch)
1. "site:youtube.com {nosso nicho} last month views"
2. "{nosso nicho} trending twitter OR reddit last 7 days"
3. Concorrentes diretos: últimos 10 vídeos publicados

### Análise de lacunas
Compare resultados da busca com o histórico interno:
- O que os concorrentes cobriram que não cobrimos?
- Há tópicos com alta demanda e baixa oferta PT-BR?
- Quais ângulos do nosso histórico são diferenciados?

## Critérios de priorização para o calendário

### Score de oportunidade (calcule para cada ideia)
- Volume de busca estimado: 1-5 pontos
- Saturação de conteúdo (menos = mais): 1-5 pontos
- Alinhamento com histórico de performance: 1-5 pontos
- Relevância para audiência atual: 1-5 pontos
- Janela de tempo (mais urgente = mais pontos): 1-5 pontos
Score total máximo: 25 pontos

### Formato de seleção
Selecione os 8 conteúdos com maior score para o mês:
- 2 conteúdos "evergreen" (sempre relevantes)
- 4 conteúdos "trending" (oportunidade atual)
- 2 conteúdos "série" (continuidade com publicações anteriores)

## Output — Calendário do Mês

### Resumo estratégico
[2-3 frases sobre o foco estratégico do mês e por quê]

### Calendário semanal
**Semana 1**
- Segunda: [título] — Score: XX/25 — Formato: [tipo]
- Quinta: [título] — Score: XX/25 — Formato: [tipo]
[... continuar para semanas 2, 3, 4]

### Para cada conteúdo do calendário
- Ângulo único: [por que nosso canal vai cobrir diferente]
- Palavras-chave primárias: [3-5 termos]
- Fonte de dados: [link ou referência que justifica a oportunidade]
- Conexão com histórico: [vídeo anterior que se relaciona]

## Atualização de memória
Ao final, atualize .claude/memory/content-calendar.md
com o calendário proposto (para referência futura).

🏆 Super Skills de Alto Valor para Criadores — Exemplos Reais

📡
signal-dashboard.md

Monitora tendências (WebSearch + WebFetch), filtra sinal de ruído, cruza com histórico do canal, gera briefing priorizado de oportunidades. Uso: toda segunda de manhã, 10 minutos.

📅
content-strategy.md

Analisa performance histórica, busca tendências de mercado, calcula score de oportunidade para cada ideia e propõe calendário mensal de 8 conteúdos com justificativa baseada em dados.

📨
sponsor-response.md

Escreve propostas de parceria usando dados reais do canal (analytics, audiência, taxa de engajamento), histórico de parcerias anteriores e benchmarks do mercado de creators. Nunca o mesmo email duas vezes.

📊
weekly-brief.md

Compila resumo estratégico da semana com: métricas vs metas, outliers identificados, decisões tomadas, oportunidades para a próxima semana. Salva resumo em memória para referência futura.

⚠️ Atenção

Super skills levam mais tempo para construir e precisam de manutenção regular à medida que o negócio evolui. Não tente construir 5 super skills ao mesmo tempo. Comece com 1, use por 30 dias, refine e só então construa a próxima. Qualidade e profundidade superam quantidade em skills estratégicas.

🗺️ Mapeando suas necessidades

O inventário estratégico é o exercício de mapear sistematicamente todos os processos repetitivos do seu negócio antes de começar a construir qualquer skill. Pular essa etapa leva a construir skills para os problemas que você lembra, não os que mais importam.

Inventário Estratégico — Exemplo Preenchido (Criador de Conteúdo)

Processo Freq./sem Contexto? Tipo Impacto Prioridade
Criação de títulos YouTube 2x Alto Super Alto 1º
Análise semanal de métricas 1x Alto Super Alto 2º
Converter blog post para thread 4x Baixo Utility Médio 3º
Resposta a emails de sponsors 3x Alto Super Alto 4º
Calcular RPM / taxa de engajamento 7x Baixo Utility Médio 5º
Formatar transcrições de vídeo 2x Baixo Utility Baixo 6º

Matriz de Priorização — Impacto × Urgência de Construção

Construir primeiro
Alto impacto + Frequente
→ Títulos YouTube
→ Análise de métricas
Construir logo após
Alto impacto + Eventual
→ Sponsor response
→ Content strategy
Fácil e rápido
Baixo impacto + Frequente
→ Thread converter
→ Metrics calculator
Postergar
Baixo impacto + Eventual
→ Formatar transcrições

Comece pelo quadrante vermelho. Os primeiros 30 dias: 1 super skill + 2 utility skills. Nada mais.

🗺️ Como Fazer seu Inventário em 30 Minutos

Passo 1

Liste todos os processos repetitivos da semana passada — sem filtrar. Tudo que você fez mais de uma vez.

↓
Passo 2

Para cada item: "Um freelancer sem briefing poderia fazer isso?" → Utility (S) ou Super (N).

↓
Passo 3

Ordene por impacto × frequência. As 3 primeiras viram seu roadmap de 90 dias.

↓
Passo 4

Construa em ordem. Meça resultado por 30 dias antes de construir a próxima.
